LAMP：从表单网站到在线协作

请求、业务、数据，各司其职

  • 约束：典型表单网站把一次操作组织成“HTTP 请求 → PHP 处理 → MySQL 读写 → 返回页面”。
  • 便利：课程报名的名额检查和报名记录可放进同一数据库事务；Web 服务、持久化与备份都有现成基础设施。

请求要结束，协作却要一直在线

  • 新增课堂实时讨论：若用 PHP-FPM 请求一直等待消息，工作进程就一直被占用；并发上限由进程池容量约束。PHP-FPM 文档
  • 可以接入 WebSocket 与消息广播，但要重新安排连接、共享状态和后台任务；Apache 本身已有 WebSocket 代理支持。Apache 文档
  • 再加入外部支付：数据库回滚不能自动撤销已完成的扣款。重试、去重和补偿需要业务自己定义，单库事务的边界显现出来。
